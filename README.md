# Delewo Media Logo Lab — Android starter

This is a starter Android project, not a finished media editor APK.

## Build
The GitHub Actions workflow builds a debug APK when you push to `main`, or when you run the workflow manually from the Actions tab.

## Current starter features
- Basic app home screen
- Choose photo, video, and audio files using Android's file picker
- Share text using Android's share sheet

## Not implemented yet
Actual photo/video editing, watermark tools, AI voice, speech-to-text, translations, social-media downloading, and full Tigrinya/Amharic/English localization are not included yet.
